# 웹 작업 지침

Next.js + TypeScript + Tailwind. 루트 지침과 관련 명세를 읽는다.

- [화면](../docs/spec/screens.md), [인증](../docs/spec/identity.md), [출석](../docs/spec/attendance.md), [얼굴](../docs/spec/face.md)을 기능별로 참고한다.
- 카메라 페이지 진입/이탈이 세션 수명이다. 전체화면 전환은 같은 세션을 유지한다.
- 학생의 얼굴 등록은 모바일, 관리자 카메라는 컴퓨터·패드·휴대폰 모두 지원한다.
- 카메라 track·타이머·구독은 이탈/로그아웃 때 정리한다. Strict Mode 재실행이 중복 세션을 만들지 않게 한다.
- QR 갱신 실패가 만료 연장으로 보이지 않게 표시한다. 종료 통지는 서버 lease와 함께 처리한다.
- 공개 환경 변수에 secret을 넣지 않는다. 역할/출석 승인 최종 판정은 서버다.
- UI는 제공 이미지와 최신 정정을 우선한다. 삭제된 공실·침대 번호·QR 이력을 디자인 그대로 복구하지 않는다.
- 오프라인은 실모델 실행이 검증되기 전 가능하다고 표시하지 않는다.
- 생성한 실제 빌드/타입/컴포넌트/브라우저 테스트 명령을 docs/verification.md에 등록한다.
