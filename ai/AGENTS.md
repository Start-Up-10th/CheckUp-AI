# AI 작업 지침

FastAPI + MediaPipe. 루트 지침과 [얼굴 명세](../docs/spec/face.md), [기술 결정](../docs/decisions.md)을 읽는다.

- 검출/랜드마크와 신원 임베딩 모델을 구분한다. 지원 범위·라이선스·실측 없이 모델을 확정했다고 쓰지 않는다.
- 동영상에서 약 100프레임을 검토하고 약 20개 대표 벡터를 저장한다. 저품질 샘플로 숫자만 맞추지 않는다.
- 원본/프레임은 메모리 처리와 즉시 정리가 원칙이다. 오류·취소·임시 파일·서버 프록시 버퍼까지 살핀다.
- 다수 얼굴은 트랙별 결과로 반환한다. unknown을 임의의 등록 학생으로 바꾸지 않는다.
- `3회 초과`와 인식 시도 단위는 DEC-004를 따른다. 영상 FPS를 실패 횟수로 쓰지 않는다.
- 한 번 등록 후 재등록하지 않으므로 모델 버전 변경 시 기존 벡터 호환성을 검증한다.
- 브라우저 오프라인 추론과 서버 FastAPI는 서로 다른 실행 환경이다. 캐시만으로 오프라인을 보장하지 않는다.
- 실학생 얼굴을 Git/로그/검사 출력에 저장하지 않는다. 성능/오인식 측정 결과만 익명화해 남긴다.
- AI가 DB 출석을 직접 변경하지 않는다. 계약은 contracts/에 기록한다.
