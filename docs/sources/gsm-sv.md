# 사용자 제공 GSM SV 정보

광주소프트웨어마이스터고등학교 학생들의 공부·프로젝트 배포를 돕는 교내 IaaS.
교내 유휴 GPU 서버 자원을 통합해 VM을 제공한다. 이 설명만으로 개별 VM의 GPU 할당을 확정하지 않는다.

| 용도 | 도메인 |
| --- | --- |
| 콘솔 | gsmsv.site |
| VM SSH | ssh.gsmsv.site |
| VM HTTP/SVC | service.gsmsv.site |

Ubuntu 22.04 LTS VM 생성, 시작/종료/재시작, SSH/HTTP/SVC 자동 포트 할당, VM 방화벽,
CPU/RAM 모니터링, VM 생성/삭제 및 리소스 경고 알림을 제공한다.
플랫폼 알림을 이 프로젝트의 학생 알림 유형으로 추가하지 않는다.

USER는 재학생 일반 계정으로 최대 3개 VM, 생성 30일 뒤 자동 삭제.
PROJECT_OWNER는 프로젝트 계정으로 제공 문서상 VM 한도·만료 없음.
가입 조건은 DataGSM 등록 GSM 재학생이다. 교육 목적 외 사용은 사전 안내 없이 삭제될 수 있다.
초기 비밀번호 변경 또는 SSH Key 설정 권장.
실제 권한·VM·주소·접속 정보는 아직 이 하네스에 제공되지 않았다.
