## 얼굴 등록 — 사용자 기능 명세 `얼굴 촬영`

- 개인정보 동의 후 휴대폰에서 진입하면 카메라가 자동 실행된다. 셔터/셀카 시작 버튼은 없다.
- 카운트다운(3→2→1) → 촬영 중 → 완료의 3단계로 진행한다.
- 자동 촬영 결과를 확인한 뒤 `다시 찍기`는 촬영본을 버리고 카운트다운부터 다시 시작한다. `완료`를 누르면 얼굴 정보로 등록하고 메인 화면으로 이동한다.
- 완료 시 등록에 실패하면 `얼굴 등록에 실패했습니다. 다시 시도해 주세요.`를 표시하고 완료 화면에 머문다.
- 미검출·저조도 안내 문구는 기존 얼굴 개인정보·품질·원본 폐기 정책을 계속 따른다. 노트북은 카메라를 열지 않고 휴대폰 등록 안내를 표시한다.

## 봉사 횟수 — 관리자 기능 명세 `봉사 횟수 가감`

- 관리 목록에서 횟수 배지 옆 `+`와 `−`를 나란히 표시하고 클릭마다 즉시 1회 가감한다. 확인 단계는 없다.
- 횟수가 0이면 `−`를 비활성화하며 0 미만으로 내려갈 수 없다.
- 조정 날짜는 기록한다. 활동명은 입력하지 않는다.
- 이 승인으로 학생 조회 범위가 활동 내역까지 확장되지는 않는다. 학생은 기존 정책대로 본인의 누적 횟수만 조회한다.
