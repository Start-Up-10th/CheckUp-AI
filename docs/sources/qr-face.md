# 사용자 제공 QR·얼굴 화면 표 전사

채팅에 붙여넣은 최신 표의 내용을 항목별로 옮겼다. 이 파일은 원자료이며 후속 변경(다수 인식·독립 공용 QR 등)은 docs/spec을 따른다.

| 항목 | 내용 |
| --- | --- |
| QR 용도 선택 | 자습실 / 기숙사 탭으로 생성 화면 전환. 기본 기숙사. |
| QR 자동 생성 | 페이지 진입 시 별도 버튼 없이 발급, 이탈 시 종료. 생성·종료 버튼·확인 모달 없음. 실패 시 `QR 자동 생성에 실패했습니다. 새로고침해 주세요.` |
| QR 자동 갱신 | 15분마다 교체. 이전 QR은 `만료된 QR입니다. 다시 스캔해 주세요.`. 갱신 실패 시 기존 QR 유지 후 재시도. |
| 남은 시간 | QR 아래 `남은 유효 시간`, mm:ss 큰 숫자 실시간 감소. 0이면 `유효 시간이 만료되었습니다.`. Mono 34px. |
| 얼굴 용도 선택 | 자습실 / 기숙사 탭, 기본 기숙사. |
| 카메라 자동 실행 | 페이지 진입 시 시작 버튼 없이 실행. 실패 `카메라를 자동으로 실행하지 못했습니다.`. 권한 거부·미연결 전용 문구 미정의. |
| 카메라 화면 | 프리뷰, 카메라 화면 라벨, LIVE, 우상단 전체화면. 연결 끊김 전용 메시지 미정의. |
| 얼굴 인식 | 얼굴 특징 추출·학생별 특징 대조. 원문에 다수 인식 예외 메시지 미정의·제외라 쓰였으나 후속 사용자 결정으로 다수 지원. |
| 성공 | 카메라 하단 잠깐 성공, 목적에 맞는 출석/입소. 같은 학생 재인식은 중복 없이 성공만 표시. |
| 실패 | 하단 잠깐 실패. 원문 `3회 초과 연속 실패 시 인식 실패 · 3회 초과 시 QR로 출석`. 비고에는 `임계값을 3회로 확정`도 있어 경계 표현이 혼재. |
| 얼굴 전체화면 | 우상단 확장 버튼, 좌상단 닫기로 복귀. 컴퓨터·패드·핸드폰 모두. QR에는 없음. |
| 최근 인식 | 이름·시각·결과, 비었으면 공통 빈 상태. |
| LIVE | 정상 카메라 동작 중 점과 LIVE. 일반 화면·전체화면 공통. |
| 전체화면 안내 | `인식 대기 중`, `가이드 안에 얼굴을 맞춰 주세요`. 성공 `성공 · 학번 이름`. |
| 최근 목록 표기 | `학번 이름 / 시각 · 성공 또는 실패`, 최신순. 성공 초록/실패 빨강. 예시 2405 김도현 / 22:04 · 성공. |

QR 생성 이력은 이 최신 표에서 이미 삭제됐다. 기능을 다시 추가하지 않는다.
