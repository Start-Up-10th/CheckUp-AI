# 서비스 범위

### REQ-SCOPE-001 — 목적과 운영 환경

광주소프트웨어마이스터고등학교 전용 기숙사 입소·자습실 출석 관리 웹 서비스다.
기숙사 자치위원이 학생을 일일이 확인하는 작업을 얼굴 인식과 QR 인증으로 줄인다.
기숙사생 약 200명, 출입구 3곳, 출입구별 기기 1대와 내장 카메라를 사용한다.
관리자는 기기 앞에 항상 있다. 별도 무인 키오스크 앱·전용 계정은 필요 없다.
학생과 관리자는 웹으로 사용한다. 목적 탭은 자습실 / 기숙사 입소이며 기본값은 기숙사다.

근거: SRC-INTERVIEW, SRC-QR-FACE.

### REQ-SCOPE-002 — 기술 스택과 담당 범위

- 웹: Next.js, TypeScript, Tailwind CSS.
- 백엔드: Java, Spring, PostgreSQL, Redis.
- AI: FastAPI, MediaPipe. 신원 대조용 임베딩 모델은 AI 담당자가 검증·선정한다.
- 배포: Docker, GitHub Actions. Docker Compose는 이전 통합안의 실행 기준이며 데브옵스가 세부 구성을 결정한다.
- 서버: 학교 GSM SV Ubuntu 22.04 VM.
- VM 사양, 이미지 저장소, 롤백, 백업 세부 방식은 담당자가 결정한다.

근거: SRC-STACK, SRC-GSMSV, SRC-HANDOFF.

### REQ-SCOPE-003 — 제외·대체된 기능

아래 항목은 현재 범위에 없다. 원문 화면에 있어도 구현하지 않는다.

- 고정 출석 시간표, 요일별 마감, 시간대 밖 인증 차단, 최종 출석 확정 버튼.
- 초기 인터뷰의 학생 지각 신청·승인 및 지각 입실 구분. 인터뷰 재시작 전 결정은 폐기됐다.
- 얼굴 동의 거부 학생의 QR 전용 가입. 얼굴 동의는 현재 필수다.
- 얼굴 원본 영상·사진의 영속 저장, 촬영본의 프로필 사진 자동 설정.
- 얼굴 등록 완료 후 재등록 기능, 재등록 요청 알림. 최초 등록 중 초기화·재촬영은 유지한다.
- QR 만료 임박 알림, QR 발급 이력·상태 배지·층별 발급.
- QR 생성/종료 버튼·종료 확인 모달·QR 전체화면.
- 얼굴 시작 버튼, 단일 얼굴만 지원하도록 범위 축소, 자동 전체화면 진입.
- 라이브니스·사진 위조 방지, 위치·GPS·지오펜싱 인증.
- 침대 번호·고정 정원·빈 방 관리, CSV 학기별 명단 업로드와 수동 호실 학생 추가/제거.
- 별도 사감 비밀번호 계정, 자치위원과 사감의 권한 차등.
- 학생 출석 과거 이력 화면, 수동 출석 수정의 사유·감사 이력·되돌리기 UI.
- 학생 봉사 활동 상세 이력 화면: 최신 사용자 결정은 자기 횟수만 조회.
- 브라우저 푸시: 직전 통합 명세의 웹 내부 알림 범위를 유지한다.

15분 QR 교체만으로 캡처 공유·대리 출석이 완전히 차단된다고 설명하지 않는다.
추가 기능은 새 사용자 요청으로 REQ를 변경한 뒤 반영한다.

근거: SRC-INTERVIEW, SRC-COMMUNITY, SRC-HANDOFF. 폐기 내역은 SRC-CORRECTIONS.
