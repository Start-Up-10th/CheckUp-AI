# student-attendance — 학생·출석 조회 계획

## 담당자·API

- 담당자: 김준수
- `GET /api/v1/student`
- `GET /api/v1/attend`
- `GET /api/v1/student/work`

## 구현

- 로그인한 학생의 프로필·학번·학년·반·번호 조회
- 현재 운영일의 본인 출석 조회
- 본인의 누적 봉사 횟수 조회
- 출석 일일 초기화와 봉사 누적 보존 분리
- `student_id`가 요청에 와도 토큰의 본인 범위를 서버에서 검증
- 학생이 타인의 출석·봉사 횟수를 조회하지 못하도록 제한

## 계약 보완

- [ ] GET body로 `student_id`를 전달하는 방식의 Spring/브라우저 호환성을 확인한다.
- [ ] 운영일을 자정이 아닌 Asia/Seoul 다음 날 08:00 기준으로 계산한다.
- [ ] 관리자 호실 전개도용 전체 학생 목록 API와 호실별 수동 출석 저장 API 부재를 계약 보완 목록에 남긴다.
- [ ] 없는 DataGSM 전체 명단 API를 임의로 만들지 않는다.

## 기준·검증

- 요구사항: `REQ-AUTH-002~003`, `REQ-ATT-001~002`, `REQ-ATT-006~007`, `REQ-COM-003`, `REQ-UI-003~004`, `REQ-UI-006`
- 수용 시나리오: `ACC-AUTH-002~003`, `ACC-ATT-001~002`, `ACC-ATT-006~007`, `ACC-COM-003`, `ACC-UI-003~004`, `ACC-UI-006`
- 학생이 다른 학생·호실의 조회 범위를 우회하지 못하는지 확인한다.
- 07:59:59→08:00, 서버 재시작, 폐기 기록 재전송을 fake clock으로 확인한다.
- 봉사 누적이 08:00 출석 정리 때 삭제되지 않는지 확인한다.
