# 기술 결정과 확인 과제

사용자는 기술 세부사항을 백엔드·AI·프론트·데브옵스에 위임했다. 이 목록은 추가 제품 인터뷰 목록이 아니다.
`기본값`은 이 하네스에서 택한 구현 해석, `검증 필요`는 외부 증거가 필요한 사항이다. 사용자 확정과 혼동하지 않는다.

## 하네스 선택

- 공유 진입은 AGENTS.md, Claude는 `@AGENTS.md`로 가져온다.
- 스킬 원본은 `.agents/skills`, Claude 검색용은 기계적으로 생성하고 검사한다. Windows 링크 권한 불필요.
- 임의로 모델·권한 우회·전역 설정·외부 MCP를 지정하지 않는다.
- 현재는 표준 Node만 쓰는 검사와 GitHub Actions 문서 CI를 제공한다. 서비스 테스트는 구현할 때 등록한다.
- 자동 Stop 훅은 넣지 않는다. 모델별 훅 지원 차이 없이 같은 로컬 명령과 CI로 검증한다.

근거와 문서 링크는 [출처 지도](sources/README.md)의 기술 자료에 있다.
