# 기술 결정과 확인 과제

사용자는 기술 세부사항을 백엔드·AI·프론트·데브옵스에 위임했다. 이 목록은 추가 제품 인터뷰 목록이 아니다.
`기본값`은 이 하네스에서 택한 구현 해석, `검증 필요`는 외부 증거가 필요한 사항이다. 사용자 확정과 혼동하지 않는다.
담당자는 증거·날짜·결과를 붙여 갱신하고 제품 의미가 달라질 때만 사용자에게 차이를 제시한다.

## 하네스 선택

2026-10-07 얼굴 지연 개선: 사용자가 기존 3품질 프레임 조건 유지와 Spring 프레임 간격 개선을 승인했다.
후보 정규화를 세션 준비로 옮기고 임베딩은 조건 통과 얼굴에만 계산한다. Spring의 200ms는 시작 간격으로
적용하고 완료 활동 시각은 만료 판단에 사용한다. 모델·threshold/margin·응답 계약은 유지한다.
[구현·검증·배포 기록](reviews/face-latency-2026-10-07.md) 참조. DEC-003의 실제 정확도·임계값 검증은 남아 있다.

- 공유 진입은 AGENTS.md, Claude는 `@AGENTS.md`로 가져온다.
- 스킬 원본은 `.agents/skills`, Claude 검색용은 기계적으로 생성하고 검사한다. Windows 링크 권한 불필요.
- 임의로 모델·권한 우회·전역 설정·외부 MCP를 지정하지 않는다.
- 현재 제공되는 것은 표준 Node 검사와 GitHub Actions 하네스 CI다. 이는 현재 구현 상태이며 CI 선구축을 제한하는 정책이 아니다. 추가 CI/CD 구성과 실행 기준은 DEC-013 및 [검증 기준](verification.md)을 따른다.
- 자동 Stop 훅은 넣지 않는다. 모델별 훅 지원 차이 없이 같은 로컬 명령과 CI로 검증한다.

근거와 문서 링크는 [출처 지도](sources/README.md)의 기술 자료에 있다.
